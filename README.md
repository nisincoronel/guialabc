# GuíaLab v13 + Desafío GuíaLab

Sitio estático listo para publicar en GitHub Pages. La guía y el desafío comparten el archivo `determinaciones.json`. El buscador incluye las prácticas incorporadas desde el Nomenclador Bioquímico Único, actualización 2026; estas entradas no se usan para generar preguntas del juego porque no incluyen datos preanalíticos.

## Publicar en GitHub Pages

1. Creá un repositorio nuevo en GitHub.
2. Subí **el contenido de esta carpeta** al nivel principal del repositorio.
3. En GitHub, abrí **Settings → Pages**.
4. En "Build and deployment", elegí **Deploy from a branch**.
5. Seleccioná la rama `main` y la carpeta `/(root)`, y guardá.

GitHub mostrará la dirección pública del sitio cuando termine de publicarlo.

## Uso

- Abrí `index.html` para consultar GuíaLab.
- Elegí la tarjeta **Desafío GuíaLab** para iniciar el juego.
- El desafío usa las determinaciones reales y genera preguntas a partir de los campos de muestra, tubo, aditivo, ayuno, procesamiento, grupo, toma y volumen aproximado.

El sitio funciona sin compilación ni dependencias instalables.
